# Experiment Analysis

## Best Performing Model

Balanced Random Forest achieved the best F1-score.

---

## Observations

- Increasing estimators improved performance.
- Balanced class weights improved minority class prediction.
- AdaBoost performed slightly lower than Random Forest.
- Hyperparameter tuning improved generalization.

---

## Conclusion

Random Forest with balanced class weights produced the most stable and accurate results for the Dry Bean Dataset.
